# Repository guidance

Before changing lesson content, card data, sequencing, practice behavior, navigation,
progress, persistence, or related UI, read and follow
the [Project Constitution](docs/project-constitution.md).

Treat the Project Constitution (or simply **The Constitution**) as the product
contract. Keep new behavior consistent across all lessons and screens. If a requested
change intentionally conflicts with The Constitution, update it in the same change and
explain the tradeoff.

Whenever a task includes creating a git commit, push that commit to the current
branch's configured remote immediately after the commit succeeds. If the push fails,
report the failure clearly and keep the local commit intact.
